Retail Suite User Guide

Guide for using the Vercel-hosted Retail Suite frontend with the Frappe backend at GMX.

Open the POS app from /retail_suite/login or the Vercel URL. Do not open files directly from /assets/retail/retail_suite/; that path is only for JavaScript, CSS, and images.

Vercel Environment

Add these variables in Vercel project settings under Settings > Environment Variables.

Name Value Purpose
VITE_API_BASE_URL https://gmx.galaxylabs.online Frappe API base URL.
VITE_SOCKET_URL https://gmx.galaxylabs.online Realtime/socket base URL.
VITE_SITE_NAME gmx.galaxylabs.online Frappe site name used by socket setup.
VITE_QZ_CERT_URL Optional Certificate endpoint for signed QZ Tray printing.
VITE_QZ_SIGNATURE_URL Optional Signature endpoint for signed QZ Tray printing.
Do not put API secrets in VITE_ variables. Vite builds those values into browser JavaScript, so users can inspect them.

Login

  1. Open the Vercel frontend URL.
  2. Enter the Frappe user email and password.
  3. After login, the app opens the POS screen.

Open POS Shift

  1. Login to the POS frontend.
  2. Open the shift dialog.
  3. Select the company.
  4. Select the POS Profile.
  5. Enter opening cash for each payment method.
  6. Submit to create the POS Opening Shift.

The app loads enabled POS Profiles from Frappe. If no profile appears, check that the POS Profile is enabled, belongs to the selected company, and has payment methods configured.

Sales Workflow

  1. Open an active shift.
  2. Add items to the cart.
  3. Select or create the customer.
  4. Review quantities, discounts, and totals.
  5. Save or submit the invoice.
  6. If auto-print is enabled, the receipt is sent to the configured terminal printer.

Thermal Printing

Retail Suite supports local USB printing through QZ Tray and network printing through ethernet printer settings.

Printer Profile Fields

  • Terminal Name: label for the cashier terminal.
  • Connection Type: USB/QZ Tray or ethernet.
  • Printer Name: local printer name for QZ Tray.
  • Host: ethernet printer IP address.
  • Port: ethernet printer port, commonly 9100.
  • Paper Width: usually 58 or 80 mm.
  • Copy Count: number of receipt copies.
  • Auto Print: print automatically after invoice save.
For USB printing, install and run QZ Tray on the cashier computer. For production signed QZ printing, configure VITE_QZ_CERT_URL and VITE_QZ_SIGNATURE_URL.

Close Shift

  1. Open the close shift dialog from the POS controls.
  2. Review expected amounts by payment method.
  3. Enter the actual counted amount.
  4. Submit the POS Closing Shift.

Any difference between expected and counted cash should be reviewed by the cashier or manager before final submission.

cd /home/dg/retail-suite
git status
git push origin main

Vercel build settings:

  • Build command: npm run build
  • Output directory: dist
  • Install command: npm install

Troubleshooting

Problem Check
Login page shows old errors Hard refresh the browser with Ctrl + Shift + R. Confirm the page is not loading an old cached bundle.
Authentication error before login The app should call retail.retail.api.auth.get_logged_user, not frappe.auth.get_logged_user.
No POS Profile appears Confirm the profile is enabled, assigned to the correct company, and has at least one payment method.
Receipt does not print Check QZ Tray is running for USB printers, or check IP/port for ethernet printers.
Vercel cannot reach Frappe Check VITE_API_BASE_URL, CORS, login cookies, and that the backend URL is reachable over HTTPS.
